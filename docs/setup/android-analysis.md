# apktool + JADX

Current Drive sources: `Android/apktool_3.0.3.jar` and `Android/jadx-1.5.5.zip`.

Java must be available first:

```bash
./kit.sh install java
./kit.sh install android-analysis
```

The installer creates local `apktool` and `jadx` wrappers and verifies both version commands.

Default workspace: `/mnt/data/android-analysis-kit`.
